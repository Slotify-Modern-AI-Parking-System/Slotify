# Slotify – Smart AI Parking Management System 🚗📍

Slotify is an AI-powered smart parking solution built with Django. It uses computer vision (OpenCV), machine learning, ALPR, and geospatial APIs to detect available parking slots in real time, recognize vehicles, and guide users with a seamless parking experience. Slotify reduces traffic congestion and environmental impact through intelligent automation.

---

## 🚀 Features

- 🔍 **Real-Time Slot Detection**  
  Detects vehicles and identifies open parking slots using YOLOv8 and OpenCV.

- 🎯 **ALPR (Automatic License Plate Recognition)**  
  Integrates ALPR to detect and recognize license plates in real time, enhancing security and automating vehicle entry logging.

- 🧠 **Smart Slot Allocation & ML Prediction**  
  Uses Django-integrated machine learning models to predict parking availability and assign optimal slots dynamically.

- 🛰️ **Navigation & Maps Integration**  
  Google Maps API guides users to the assigned slot via the shortest route.

- 📱 **Web Interface (Django Templates)**  
  Mobile-friendly UI for booking slots, real-time status updates, and digital payments.

- 📊 **Admin Dashboard**  
  Parking lot owners and city managers can monitor availability, revenue, and analytics in real time.
  

## 🛠️ Tech Stack

- **Framework**: Python, Django
- **Computer Vision**: OpenCV, YOLOv8
- **ALPR**: Custom OCR + License Plate Detection
- **Machine Learning**: Scikit-learn, Predictive Models
- **Frontend**: Django Templates (HTML/CSS/JavaScript)
- **Database**: SQLite 
- **APIs**: Google Maps API, Payment Gateway APIs
